## Необходимо создать новостной портал.

Должны быть возможности по добавлению, редактированию и удалению новости, а так же список всех новостей (заголовок и анонс) с постраничным переходом и возможностью просмотреть новость полностью.

Данные должны храниться в базе.

При реализации не использовать фреймворки.
